# تعليمات دمج مكتبة AERVIX TV في Codex

1. اقرأ assets/README_AR.md وassets/assets_manifest.json، ثم شغّل python tool/validate_design_assets.py. لا تغيّر الواجهة إذا فشل الفحص.
2. استخدم خلفية assets/backgrounds/jeddah_background_fhd.png افتراضيًا مع BoxFit.cover أو contain وحفظ النسبة؛ لا تحمل نسخة 4K في MECOOL افتراضيًا. نسخة 4K معاد بناؤها/محسّنة وليست أصلية.
3. اعرض طبقة التعتيم والموجات بشكل مستقل. لا تستخدم صورة التصميم المسطحة أو أي صور بيانات داخل خلفية الواجهة.
4. خصص نطاقًا ثابتًا للمعلومات بين y=116 وy=516 على لوحة 1600×900. لا تسمح بلوحة الطقس/الساعة أو الصلاة بالامتداد إلى صف التطبيقات الذي يبدأ y=525. عند تكبير خط الجهاز، صغّر محتوى نطاق المعلومات بـ FittedBox.scaleDown داخل عرض محدود؛ لا تخفِ القيم ولا تضع اللوحات فوق التطبيقات.
5. تبقى بيانات الساعة والطقس والمواقيت برمجية، ونصوص العربية RTL. استخدم أيقونات الطقس بحسب الحالة والنهار/الليل، لا صورة ثابتة للشمس لكل الحالات.
6. استخدم الأيقونات المستقلة للشرائط والأقسام، وإطارات PNG بخاصية nine-slice للزوايا عند الحاجة. لا تمدد الأيقونات أو الشعارات؛ استخدم BoxFit.contain. لا تضع أسماء الأقسام داخل الصور.
7. تظل التطبيقات ومشغلاتها وأيقوناتها الفعلية من AppsService/PackageManager؛ أيقونات المكتبة الموثقة للمعاينة أو الاستخدام القانوني المناسب فقط، ولا تستبدل التطبيقات المثبتة بأسماء ثابتة. شعار Yacine TV من الجهاز؛ لا يوجد بديل تخميني في الحزمة.
8. احتفظ باختصارات D-pad وOK وEnter والرجوع، وبانتقال تحديد 180ms. حافظ على ImageCache، واستخدم صورًا صغيرة مفكوكة مرة واحدة. تجنب BackdropFilter والتمويه الديناميكي لكل بطاقة.
9. لا تغيّر applicationId=com.omeda.arc أو مفاتيح AERVIX_RELEASE_* الأربعة أو بيانات المستخدم أو قاعدة البيانات أو وظائف التحديث والتشغيل.
10. اختبر RTL والتنقل عبر صف طويل والرجوع والتحديث، وافحص هندسة اللوحات مع textScaler=1.5 و2.0 على FHD و4K. نجاح عدم ظهور استثناء لا يكفي: افحص حدود العناصر للتأكد من عدم التداخل.
11. قبل نشر أي APK ارفع versionName وversionCode، ثم استخدم workflow التوقيع والنشر الحالي. قارن الحزمة والشهادة والإصدار مع release-manifest.json للإصدار السابق. لا تنشئ أو تستبدل مفتاحًا.
