# Xtream Codes — الإصدار 1.3.1

البطاقات الثلاث والقائمة والخلفية لم تتغير. البث والأفلام والمسلسلات في الصفحة الرئيسية تفتح الآن محتوى الاشتراك داخل التطبيق بدل مشغلات خارجية. شريط التطبيقات لا يزال يشغّل التطبيقات المثبتة نفسها.

## الاشتراك

لم يكن في الإصدار 1.3.0 أي مخزن Xtream أو اشتراك مدمج. عند أول فتح قسم، يظهر حوار لإدخال هوست واسم مستخدم وكلمة مرور، أو لصق رابط get.php/player_api.php كامل. تُتحقق صلاحية الحساب قبل استبدال أي اشتراك، ويُحفظ باستخدام flutter_secure_storage والتخزين المشفّر في Android. لا تُدرج بيانات الدخول في المصدر أو GitHub أو رسائل الخطأ.

في الفتحات التالية يُعاد استخدام الاشتراك تلقائيًا. يمكن تغييره من زر الحساب داخل متصفح المحتوى. توجد قراءة توافقية لمفاتيح xtream_account أو xtream_host/xtream_url وxtream_username وxtream_password إن وُجدت، دون حذفها أو تغيير إعدادات المشغّل القديمة. هذا ليس استيرادًا من بيانات تطبيقات أخرى؛ لا يمكن قراءة اشتراك Yacine أو غيره من مساحة بياناته الخاصة.

يدعم http وhttps حسب عنوان المستخدم دون تعطيل فحص شهادات HTTPS. بيانات الاشتراك الجديدة المشفّرة تستثنى من النسخ الاحتياطي/النقل إلى جهاز آخر لأنها مرتبطة بمخزن Android على الجهاز؛ قواعد النسخ لبقية الإعدادات وقاعدة البيانات محفوظة.

## المحتوى والريموت

- البث: get_live_categories وget_live_streams، وتشغيل /live/... داخل video_player/ExoPlayer.
- الأفلام: get_vod_categories وget_vod_streams، وفحص get_vod_info قبل التشغيل الداخلي /movie/....
- المسلسلات: get_series_categories وget_series وget_series_info، وفرز المواسم وأرقام الحلقات ثم تشغيل /series/....
- ↑ ينتقل للقناة التالية و↓ للسابقة ضمن قائمة التصنيف نفسه، مع حفظ ترتيب الهوست. عند الطرف يبقى على أول/آخر قناة ولا يقفز لتصنيف آخر. البحث لا يغيّر قائمة التبديل؛ يعود التبديل لترتيب التصنيف الذي اختيرت منه القناة.
- الاسم والرقم داخل التصنيف يظهران ثلاث ثوانٍ. رجوع يعيد قائمة القنوات ويوقف تشغيلها. موافق يوقف/يستأنف؛ عند الخطأ يعيد المحاولة.
- في الأفلام والحلقات، ← و→ يرجعان/يقدمان عشر ثوانٍ، ولا يبدلان القنوات. لا يتم فتح مشغل خارجي.
- ضغطات التبديل المتتابعة تُدمج خلال 75ms، ويُوقف الصوت والمشغّل السابق قبل إنشاء التالي. زمن تحميل الفيديو نفسه يعتمد على الهوست والترميز والشبكة والجهاز؛ لا ندّعي تبديلًا بلا buffering.
- زر القائمة أو M أو زر X أو قائمة النقاط بجانب العنصر يتيح المفضلة والحظر. زر «حظر التصنيف» يحجب التصنيف، وزر الحظر العلوي يدير الحظر اليدوي.

الفلترة مبنية على بيانات الهوست والكلمات والوسوم، وليست تحليلًا بصريًا لكل فيديو؛ لا يمكن ضمان اكتشاف محتوى يسميه المزوّد باسم بريء ويخفي جميع وسومه. الحظر اليدوي يعالج الحالات المتبقية. لا يظهر عنوان المحتوى المحظور في إدارة الحظر؛ تعرض أرقام العناصر فقط.

## الأيقونات والأداء

أيقونات PackageManager الأصلية ترسم بنسبة أبعادها مع هامش شفاف داخل 512×512، دون اقتصاص أو تغيير تصميم الشريط. واجهة Flutter تعرضها بـ BoxFit.contain داخل مساحة ثابتة. طلبات الأيقونة المتزامنة تشترك في Future وذاكرة مؤقتة، وتُبطل عند تحديث/إزالة الحزمة. الأيقونة غير المتاحة ترجع رمزًا بديلًا دون انهيار.

القوائم تبنى عند الطلب، والبحث مؤجل 220ms، وتحليل JSON الكبير ومعالجة/فلترة القوائم من 500 عنصر يعملان خارج خيط الواجهة. لا يتم تنزيل كل روابط البث أو فحصها مسبقًا أثناء تبديل القنوات. لا تغيير لمخطط قاعدة البيانات أو الصور أو توقيع APK أو اسم الحزمة com.omeda.arc.
