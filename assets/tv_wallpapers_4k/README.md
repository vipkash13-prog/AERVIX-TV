دقة التسليم UHD لا تعني أن المصادر صُوّرت أو وُلّدت أصلاً بدقة 4K. جميع الملفات موسومة `native_4k: false` في `assets_manifest.json`، مع أبعاد المصدر وبصمة SHA256 وطريقة التجهيز.
